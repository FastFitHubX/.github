# FastFitHubX

Welcome to the official GitHub organization for FastFitHubX, the decentralized ecosystem that rewards physical activity through the Proof-of-Workout (PoWk) protocol.

## Our Mission

FastFitHubX is dedicated to incentivizing a healthier lifestyle by bridging the gap between physical fitness and blockchain technology. Our protocol ensures that every drop of sweat is verified, recorded, and rewarded.

## Core Components

- **[HubXCoin ($HUBX)](https://github.com/FastFitHubX/hubx-contracts)**: The native utility token that powers the FastFitHubX ecosystem.
- **[Proof-of-Workout (PoWk) Protocol](https://github.com/FastFitHubX/hubx-proof-of-workout)**: Our proprietary consensus mechanism for verifying physical activity data.
- **[Developer SDK](https://github.com/FastFitHubX/hubx-sdk)**: A developer-friendly toolkit for integrating PoWk verification into external applications.
- **[Whitepaper](https://github.com/FastFitHubX/hubx-whitepaper)**: The comprehensive guide to our vision, technology, and tokenomics.
